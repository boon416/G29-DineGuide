# DineGuide 🍽️

DineGuide is a simple yet interactive Android application designed to help users decide what to eat using a fun spinwheel. It also allows users to browse restaurants, pin favorites, and view their spin history. The app integrates Firebase for authentication and real-time database features.

---

## 🔧 Features

- 🎡 Spinwheel-based restaurant selection
- 🔍 Browse restaurants with search and filtering
- 📌 Pin favorite restaurants (requires login)
- 🕓 View spin history (linked to each user)
- 🌐 Open restaurant location in Google Maps
- 🔐 Firebase Authentication (Login & Register)

---

## 🧪 How to Run

1. Clone or download this repository
2. Open it in **Android Studio**
3. Sync Gradle and connect to an Android emulator or device
4. Run the `app` module

> ⚠️ Make sure to connect your own Firebase project or replace the existing `google-services.json` if needed.
